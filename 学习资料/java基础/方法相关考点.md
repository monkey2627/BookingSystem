# 方法相关考点

---

## 一、方法的内存模型

### 栈帧（Stack Frame）

Java 每调用一个方法，JVM 就在**当前线程的虚拟机栈**上压入一个栈帧；方法执行完毕后，栈帧弹出销毁。

一个栈帧包含：

| 区域 | 内容 |
|------|------|
| 局部变量表 | 方法参数 + 方法内定义的局部变量 |
| 操作数栈 | 执行字节码指令时的临时数据 |
| 动态链接 | 当前方法所属类的运行时常量池引用 |
| 返回地址 | 方法执行完毕后跳回的位置 |

```
Thread Stack（线程虚拟机栈）
├── 栈帧 n（当前正在执行的方法）← 栈顶
├── 栈帧 n-1（调用者方法）
├── ...
└── 栈帧 1（main 方法）
```

**记忆要点**：方法里定义的局部变量（包括基本类型和引用类型的引用本身）都在**栈**上；对象实体在**堆**上。

### 方法区（元空间）

类的字节码（方法的指令序列）存放在**方法区/元空间**，不是栈。栈帧里存的是该方法对应字节码的**执行上下文**（局部变量、操作数等），指令本身在元空间。

## 二、基本类型与引用类型

### 基本数据类型（Primitive Types）

包括：`byte`、`short`、`int`、`long`、`float`、`double`、`char`、`boolean` 共 8 种。

- **变量本身存储的是真实的值**，在栈上占据固定大小的空间（如 `int` 占 4 字节）。
- 赋值时直接复制值本身，两个变量相互独立。

```java
int a = 10;
int b = a;   // b 得到 10 的副本
b = 20;      // 修改 b 不影响 a
System.out.println(a);  // 10
```

### 引用数据类型（Reference Types）

包括：类（`class`）、接口（`interface`）、数组（`[]`）、枚举（`enum`）等所有非基本类型。

- **变量存储的是堆上对象的内存地址（引用）**，引用本身在栈上；对象实体在堆上。
- 赋值时复制的是地址，两个变量共享同一个堆对象。

```java
int[] arr1 = {1, 2, 3};
int[] arr2 = arr1;   // arr2 保存和 arr1 同一个地址
arr2[0] = 99;
System.out.println(arr1[0]);  // 99，共享同一个数组
```

## 三、方法传参：全部都是值传递

Java 中**没有引用传递**，所有参数传递都是**值的复制**：

- 传基本类型 → 复制值本身，方法内修改不影响调用方
- 传引用类型 → 复制地址值，方法内**通过地址修改对象内容会影响调用方**，但**重新给形参赋值（让形参指向新对象）不影响调用方**

```java
// 示例 1：基本类型，方法内修改无效
void addTen(int n) {
    n += 10;   // 修改的是 n 的副本
}
int x = 5;
addTen(x);
System.out.println(x);  // 5，不变

// 示例 2：引用类型，通过引用修改对象内容有效
void fillArr(int[] arr) {
    arr[0] = 100;  // 通过地址修改堆上对象
}
int[] nums = {1, 2, 3};
fillArr(nums);
System.out.println(nums[0]);  // 100，已修改

// 示例 3：引用类型，让形参指向新对象，对调用方无效
void reassign(int[] arr) {
    arr = new int[]{9, 9, 9};  // 让形参副本指向新对象，原引用不变
}
int[] nums2 = {1, 2, 3};
reassign(nums2);
System.out.println(nums2[0]);  // 1，不变
```

**一句话总结**：Java 传参永远是复制，对于引用类型复制的是地址，通过地址能修改堆上内容，但无法让调用方的变量指向新对象。

## 四、方法重载（Overloading）

**同一个类**中，方法名相同，但**参数列表不同**（参数类型、个数或顺序至少有一项不同）。

```java
int add(int a, int b)      { return a + b; }
double add(double a, double b) { return a + b; }  // 参数类型不同，合法重载
int add(int a, int b, int c)  { return a + b + c; }  // 参数个数不同，合法重载
```

**重载不能靠返回值区分**（编译器在调用处只看参数，不看返回值）：

```java
int foo(int a)    { return a; }
// double foo(int a) { return a; }  // 编译错误，只有返回值不同
```

**重载解析时机**：编译期，编译器根据参数类型在源码处选定方法，属于**静态绑定**。

## 五、方法重写（Overriding）

子类**覆盖**父类（或接口）中的同名、同参、同返回类型（或协变返回类型）的方法。

约束条件：
- 访问权限**不能更严格**（子类可以放宽，不能收窄）
- 不能抛出比父类**更宽泛的受检异常**
- 静态方法、`final` 方法、私有方法不能被重写
- `@Override` 注解会让编译器帮你验证是否真的构成重写（推荐加）

**重写选择时机**：运行期，JVM 根据对象的**实际类型**选定方法，属于**动态绑定（虚方法分派）**。

```java
class Animal {
    void speak() { System.out.println("..."); }
}
class Dog extends Animal {
    @Override
    void speak() { System.out.println("汪汪"); }
}

Animal a = new Dog();  // 编译期类型 Animal，运行期类型 Dog
a.speak();             // 输出"汪汪"，动态绑定到 Dog.speak()
```

## 六、可变参数（Varargs）

`类型... 参数名` 语法，本质是**数组的语法糖**，方法内当数组使用。

```java
int sum(int... nums) {
    int total = 0;
    for (int n : nums) total += n;
    return total;
}
sum(1, 2, 3);          // 传多个值
sum(new int[]{1, 2}); // 也可以传数组
```

**约束**：可变参数只能是方法的最后一个参数；每个方法只能有一个可变参数。

## 七、常见考题速查

| 考点 | 结论 |
|------|------|
| 方法内局部变量存在哪里 | 栈帧的局部变量表 |
| 对象实体存在哪里 | 堆 |
| 传 `int` 进方法，方法内修改，调用方变吗 | 不变（值复制） |
| 传 `int[]` 进方法，方法内 `arr[0]=99`，调用方变吗 | 变（通过引用改了堆上内容） |
| 传 `int[]` 进方法，方法内 `arr = new int[]{}`，调用方变吗 | 不变（形参指向了新对象，原引用不动） |
| 重载靠什么区分 | 参数列表（类型/个数/顺序），和返回值无关 |
| 重载是静态还是动态绑定 | 静态绑定（编译期确定） |
| 重写是静态还是动态绑定 | 动态绑定（运行期按实际类型） |
| `String` 传进方法能改内容吗 | 不能，String 不可变；重新赋值对调用方无效 |
