# Java 隐式类型转换（自动转换）
## 一、什么是隐式转换
**不需要手动写强制转换符 `(类型)`，程序自动完成的类型提升**。
核心规则：**小范围类型 → 大范围类型，安全无损，自动转**。

## 二、基本数据类型转换优先级（从小到大）
```
byte(1) < short(2) < int(4) < long(8) < float(4) < double(8)
char(2)
```
char 可以直接提升为 int（存 ASCII/Unicode 值）

### 自动转换场景 1：赋值
小类型变量赋值给大类型变量，自动隐式转换
```java
byte a = 10;
int b = a; // byte → int 隐式转换，没问题

char c = 'A';
int num = c; // char → int，自动转成ASCII 65

int i = 100;
double d = i; // int → double
```

### 自动转换场景 2：运算时（算术提升）
表达式中有多种类型，**全部统一提升到范围最大的类型**
1. 只要有 double → 整体 double
2. 否则有 float → 整体 float
3. 否则有 long → 整体 long
4. 剩下 byte/short/char 全部先转 int 再计算

```java
byte b = 3;
short s = 5;
int res = b + s;
// b和short运算先自动转int，结果int

int x = 2;
double y = 3.5;
double sum = x + y; // int自动转double再相加
```

### 自动转换场景3：方法传参
实参类型小，形参类型大，自动转换
```java
public static void test(double d){}

public static void main(String[] args) {
    test(10); // int 隐式转 double
}
```

## 三、char 特殊隐式转换
char 本质是无符号 2 字节整数，能直接转 int/long/float/double
```java
char ch = '9';
int val = ch; // '9' 的Unicode值57
```

## 四、不会自动隐式转换的情况（会编译报错）
大范围 → 小范围，可能丢失精度，Java 不允许自动转，必须强转
```java
int a = 100;
byte b = a; // 报错，int不能自动转byte
double d = 3.14;
int i = d;  // 报错，小数丢精度
```

## 五、常量特殊隐式转换（byte/short/charr 独有）
**编译期常量**：右边是字面量且数值在目标类型范围内，可以自动赋值
```java
byte b = 127; // 合法，127在byte范围
byte b2 = 128;// 报错，超出范围

short s = 'A'; // char常量在short范围，允许
```
如果是变量就不行：
```java
int num = 10;
byte b = num; // 变量，不自动转换，报错
```

## 六、字符串拼接的隐式转换（高频考点）
任意类型和 `String` 用 `+` 拼接，其他类型自动隐式转为字符串
```java
System.out.println(10 + "abc"); // "10abc"，int转String
System.out.println(true + "");  // "true"，布尔转String
System.out.println(3.14 + "x"); // "3.14x"
```
注意运算顺序：
```java
System.out.println(1 + 2 + "3"); // 先1+2=3，再+"3" → "33"
System.out.println("3" + 1 + 2); // 先"3"+1="31"，再加2 → "312"
```

## 七、boolean 不参与任何数值转换
`boolean` 和 byte/int/char 等**完全不能互相转换**，无隐式、无强制转换。
```java
boolean flag = true;
int x = flag; // 直接编译报错
```

## 八、隐式转换总结口诀
1. 小转大，自动隐式；大转小，必须强转；
2. byte/short/char 运算一律先提升 int；
3. 浮点数参与运算结果一定浮点；
4. 常量数字在范围内可直接赋值给 byte/short；
5. +拼接字符串，所有类型自动变 String；
6. boolean 不和数字互转。
