### 各业务模块

#### 用户模块
- `POST /api/user/register`：手机号注册，重复检测
- `POST /api/user/login`：Sa-Token 登录，返回 token + 用户信息

#### 商家模块
- `PUT /api/merchant/info`：upsert 商家信息，null 字段不覆盖
- `GET /api/merchant/{id}`：查商家详情，**已加 Cache Aside 缓存**（防穿透 + 防击穿 + 防雪崩）
- `GET /api/merchant/search`：分页搜索，`JSON_CONTAINS` 过滤服务类型，SQL 在 `MerchantMapper.xml`

缓存策略：
- Redis key：`merchant:info:{id}`，TTL 随机 25~35 分钟（防雪崩）
- 不存在时写空值哨兵 `""`，TTL 2 分钟（防穿透）
- Redisson 锁 + 双重检查防击穿
- 更新信息后 `delete` 缓存 key（Cache Aside 写策略）

#### 档期模块
- `POST /api/schedule`：商家创建档期，校验重复、抢档期必填开放时间
- `GET /api/schedule/merchant/{id}?month=2024-01`：按月查档期列表，含排队人数
- `POST /api/schedule/{id}/rush`：**Lua 脚本原子抢档期**，防并发超额

Lua 脚本（`resources/lua/rush.lua`）：
- Redis ZSET 存排队队列，`ZSCORE` 查重、`ZCARD` 查满、`ZADD` 入队、`ZRANK+1` 返回名次
- 返回 `-1`=已在队列，`0`=队满，正整数=排队名次
- Lua 成功后同步写 DB `rush_record` 表

#### 订单模块
- `POST /api/order`：下单，**Redisson 分布式锁** `order:create:{userId}:{scheduleId}`，双重检查防重复下单
- `GET /api/order/my`：客人订单列表（游标分页，`lastId` 参数）
- `GET /api/order/received`：商家收单列表（游标分页）
- `PUT /api/order/{id}/confirm`：商家确认
- `PUT /api/order/{id}/complete`：标记完成
- `PUT /api/order/{id}/cancel`：取消，恢复档期状态为空闲

游标分页：查 `size+1` 条判断 `hasMore`，返回 `{list, hasMore, nextCursor}`，无 COUNT 查询。

#### 评价模块
- `POST /api/review`：提交评价（校验订单归属、状态=已完成、未重复评价），同步重算商家 avgScore
- `GET /api/review/merchant/{id}`：评价列表，页码分页
- `PUT /api/review/{id}/reply`：商家回复

#### 动态模块
- `POST /api/post`：发布动态（图片 URL 存 JSON 数组）
- `GET /api/post/merchant/{id}`：游标分页，`@TableLogic` 软删除
- `DELETE /api/post/{id}`：逻辑删除

#### 消息模块
- `POST /api/message/send`：发送消息
- `GET /api/message/history`：拉取历史消息（游标分页），同时批量标记已读
- 注：REST 接口，仅支持拉取历史；实时推送需 WebSocket（后续阶段）

#### 问卷模块
- `POST /api/questionnaire`：商家创建问卷模板，`ObjectMapper` 校验 questions 是合法 JSON
- `GET /api/questionnaire/merchant/{id}`：查问卷，`questions` 字段返回解析后的 JsonNode

#### 投诉模块
- `POST /api/complaint`：提交投诉，自动判断投诉方/被投诉方（客人投诉商家 or 商家投诉客人）

#### 图片上传
- `POST /api/upload`：七牛 CDN 上传，校验类型（jpg/png/webp）和大小（≤5MB），UUID 文件名，返回完整 CDN URL
- 配置：`config/QiniuConfig.java`，读 `application.yaml` 中 `qiniu.*` 配置
